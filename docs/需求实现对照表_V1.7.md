### J04 实现说明（已完整）

文档要求「系统自动对比三条预测与现实录入，输出偏差分析」。当前实现为**双轨**：

1. **手动逐条勾选**（保留）：用户对「预测是否与现实吻合」判断最可靠，且 J07 本身要求「用户可编辑修正」。
2. **AI 自动语义对比**（已接入）：复盘页「🤖 AI 帮我分析」按钮 → `/api/deviation` 端点（输入 3 条预测 + 现实情况 → 输出准确项/偏差项/原因），自动勾选 radio + 归类偏差原因，用户可再人工修正。

两者互补，J04 已完整实现。

## 六、技术要点备忘

- **后端薄代理**：FastAPI + DeepSeek，只做 LLM 中转（parse/deduce/recalc），数据全部存前端 IndexedDB。
- **数据主权**：档案/快照/复盘/待办存浏览器本地，JSON 导入导出，后端不落库。
- **成本控制**：一致性系数仅完整度≥70% 触发（3 次并行）；参数微调重算短 prompt 低成本；SimHash 复用省重复调用。
- **部署链路**：Cloudflare Tunnel → stock-agg(8000) → /history-plan/ 代理 → history-plan(8023)。

## 七、V1.8 登录系统（增量，2026-09-05）

> V1.7 定位「无账号」，V1.8 应需求新增账号体系，**数据主权不变**（档案仍存本地 IndexedDB，后端仅存账号 + 额度元数据）。

| 项 | 说明 |
|---|---|
| 后端 | `accounts` 表（username + pbkdf2_hmac 密码 + salt）；`_sessions` 内存 token；`resolve_identity` 把身份统一为「登录 = `u:用户名` / 匿名 = device_id」 |
| 端点 | `/api/auth/register` `/api/auth/login` `/api/auth/logout` `/api/auth/me` |
| 配额绑定 | 登录后额度跟账号走（`u:用户名`），匿名额度跟 device_id 走，互不干扰；免费 3 次终身不变 |
| 前端 | Login.vue（登录/注册切换）+ 导航栏登录态（用户名 badge + 登出按钮）+ token 存 localStorage |
| 安全 | pbkdf2_hmac(sha256, 100k 迭代) + secrets 盐；token 为 secrets.token_hex(32)；密码比对用 compare_digest 防时序攻击 |
| 附带 | 案例引用频次统计持久化到 `case_stats` 表（原内存态，重启丢失） |

**未做（V2 规划）**：数据云同步（登录后跨设备）、付费墙真实支付、快照归档、低频案例归档、软校验待审核队列后台。
