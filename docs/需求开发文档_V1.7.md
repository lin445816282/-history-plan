项目概述1.1 项目背景用户希望建立一套工具，记录个人/多个人物现实条件，借鉴历代历史人物成败事理、时代大势规律，对未来发展做推演；不仅评估成事概率，同时辨析代价取舍，区分人为抉择与外部时运变局，输出可落地计划；并且可以持续更新档案、复盘预测与现实结果。核心逻辑：时代大势 + 个人禀赋 + 心性取舍 + 现有资源 + 现实约束 + 外部变局 + 目标 → 多条发展路径（含守正待时路径） + 可行性评分（含评分依据+置信区间）+ 得失权衡 + 风险预警 + 止损阈值（含心理执行难度）+ 行动方案 + 心性修炼建议（含每周微行动）+ 行动计划跟踪器 + 偏差自检报告1.2 项目目标· 支持多人物档案独立管理，每个人物档案隔离，互不干扰；可新建、编辑、删除、复制档案。· 支持三种录入模式：极速建档（3项必填+对话式追问）、简易自然语言快速录入、完整表单录入；AI自动解析生成标准化档案，禁止脑补编造信息；表单扩展字段默认折叠，降低填表负担。· 档案时间轴叙事视图：将过往经历、目标、关键事件按时间线可视化呈现，增强代入感与持续更新意愿。· 内置历史知识库，兼顾成功案例与失败教训，区分古代语境与现代现实；新增近现代行业人物原型子库（覆盖科技、制造、文创、教育、商业、医疗6大领域）；每条案例预置"古今转化行动原则"；包含时代规律、人物原型、知止避祸守成素材。· 调用大模型完成推演计算，输出结构化推演报告：一分钟速览摘要、历史对标（含大势周期分析）、同侪参照、多条可选路径（含守正待时路径）、可行性评分（点估计+95%置信区间+评分依据明细） 、得失权衡（含转换成本）、止损触发阈值（含心理执行难度）、优劣势、历史风险陷阱、分阶段行动计划、心性修炼建议（含每周微行动） 、预警条件、敏感性分析、外部环境客观提示。· 行动计划跟踪器：从报告中自动提取短期行动项，生成待办看板，用户勾选完成状态，完成进度自动关联到复盘模块，实现"推演→执行→复盘"闭环。· 推演偏差自检报告：复盘时系统自动对比推演预测与现实结果，输出偏差分析（预测准确项/偏差项及原因），提升系统透明度与用户长期信任。· 报告语音播报：支持一键朗读报告摘要（一分钟速览+最佳路径+本月行动），基于浏览器原生Speech Synthesis API，无需额外成本。· 支持档案迭代更新，重新推演；保存推演快照，实现历史可回溯（快照绑定知识版本+提示词版本）；复盘模块区分人为抉择、外部时运变局，增加自我同情引导。· 支持推演报告导出（Markdown + PDF），便于存档查阅。· 数据一键备份与恢复：支持导出全部数据为JSON文件，及导入恢复，解决无账号体系下的数据安全焦虑。· 全局多重边界声明：本系统不提供算命占卜、投资理财建议、心理咨询、法律意见；输出强制附带史观免责声明，明确推演为事理参考，不是宿命定数。· 移动端基础适配：报告页在手机屏幕宽度≥375px下可完整阅读，所有按钮不小于44px触控区域。1.3 非目标（范围排除）· 不做算命、占卜、玄学预测；不输出注定命运结论。· 不提供投资、理财、交易、心理诊疗、法律判决类专业建议。· V1版本不做用户注册登录，档案存储于站点本地；后续版本可扩展账号体系。· V1不实现：二选一专项对比推演、多条件对照推演、用户自定义历史案例、移动端深度适配（仅做基础可读性适配）。2. 用户角色角色 说明普通使用者 系统使用者，创建多个人物档案（自己、家人、模拟人物），录入信息，发起推演，查看结果，复盘修改档案，导出报告。重视自省，能够区分推演参考与现实定数。可通过行动计划跟踪器持续跟进执行，通过偏差自检报告评估系统可信度。系统管理员 维护历史知识库，更新历史案例、提示词模板，管理知识版本；审核疑似违规输出队列；V1版本暂不做独立前台后台。3. 六层架构体系（架构‑业务‑数据‑知识‑外部‑运维，每层附带约束管理）全局顶层约束（所有层必须遵守）· 真实性约束：所有人物信息只能来源于用户输入，严禁模型臆造；未提及字段留空。· 可回溯约束：每一次推演留存档案快照，历史推演结果不可篡改；快照同时绑定知识库版本号与提示词版本号。· 边界约束：定位为概率事理参考，严禁输出宿命、定数类结论；输出融合传统史观表述；拦截投资、心理诊断、法律建议类输出。· 解耦约束：各层之间仅通过契约交互，禁止跨层侵入内部实现。· 容错约束：信息缺失、外部服务异常，给出明确提示，不阻断用户操作。· 数据主权约束（V1.7新增）：用户全部数据（档案、快照、复盘、待办）归用户所有，导出格式为开放JSON，不绑定特定系统版本。3.1 架构层｜定骨架划边界｜约束防越界核心职责：分层划分、模块边界、依赖关系、扩展预埋、技术选型、整体边界定义。约束管理· 模块高内聚低耦合，禁止跨层直接读写数据；接入层只做交互转发，业务逻辑全部收拢业务能力层。· 明确系统边界：不做算命、不做投资建议、不做心理咨询、不做法律意见；全局配置拦截玄学、专业咨询类输出。· 预埋扩展点：预留用户身份隔离、知识库可编辑、多模型切换接口占位，V1不实现。· 架构预留古今语境标记、太平世/乱世标签的承载能力，历史案例必须携带时代背景标识、古今转化行动原则，防止刻舟求剑式类比。· 架构预留近现代行业人物原型子库的接入能力，与古代案例库并行存在，推演时根据用户行业自动匹配。· 架构预留"待办→复盘"自动关联能力（V1.7新增）：行动计划跟踪器的完成记录可作为复盘模块的输入数据，减少用户重复录入。3.2 业务层｜编排业务流程｜约束守规则核心职责：业务域划分、流程编排、场景实现、业务规则落地。约束管理· 解析域与推演域严格分离；解析阶段禁止加载历史知识库；仅推演阶段注入历史知识上下文。· 推演强制生成档案快照，快照独立存储；原始档案修改不影响旧推演记录。· 极速建档流程：用户仅需填写3项必填内容（①姓名 + ②核心目标 + ③当前最大困境），提交后系统自动生成初始档案，并通过对话式追问逐步补全关联字段（每次只追问1项，形成对话流）。未追问到的字段保持空白，不阻塞建档。· 简易录入解析完成后强制进入预览校验页，不允许直接跳过保存；高亮AI提取内容（蓝色）、空白待补（灰色）、存疑字段（红色提示复核）。· 复制档案仅复制人物画像本体，不连带复制推演、复盘记录、待办事项，生成全新独立实例。· 推演输出必须包含守正待时（稳健守成）路径；每条路径增加得失权衡维度，不只评判能不能成，还要辨析是否值得为之；新增止损触发阈值及心理执行难度评估。· 复盘区分「人为抉择因素」与「外部时运变局」，增加自我同情引导问题。· 复盘时自动触发偏差自检（V1.7新增）：用户录入现实情况后，系统自动对比该次推演报告中的三条关键预测（推荐路径、最大风险、心性提醒），输出偏差分析报告。· 推演前做档案完整性校验；关键字段大量缺失给出警告，允许选择继续推演（可信度低）或返回完善档案。· 表单交互：扩展可选字段默认折叠隐藏，用户需要时手动展开填写，避免填表负担。· 最小可行档案标准：定义推演有效触发的最低数据门槛，包括必填核心三元组：①明确目标 + ②当前核心处境 + ③主要现实约束。档案完整度评分低于60分（基于核心字段覆盖率）时，系统强制弹出引导补全弹窗，并提供"直接推演（结果可信度极低）"与"前往补全信息"两个选项。· 推演置信度分级：每份推演报告必须附带报告可信度综合评级（高/中/低/极低），该评级由"档案完整度评分（权重40%）+ 推演一致性系数（权重40%）+ 历史案例匹配度（权重20%）"加权计算得出。其中推演一致性系数通过以下方式获得：对同一档案以低温度参数（0.3）进行3次并行推理，计算各路径可行性评分的标准差，标准差越小表示推理越稳定、一致性越高。（注：为控制成本，此3次并行推理仅对档案完整度≥70%的请求执行；完整度<70%时，一致性系数固定为"中"档。）评级为"低"或"极低"的报告，顶部用醒目色块标注提示。· 参数微调·快速重算：推演报告页面底部提供"参数微调"面板，用户可调整3~5个关键数值变量（如资金数额、时间投入），以滑动条形式呈现。点击"重算"后，系统复用原推演的推理上下文，仅对受影响部分（可行性评分、风险提示等）做增量更新，响应时间≤3秒，成本约为完整推演的20%。前端展示"调整后分数变化"对比条。· 行动计划跟踪器业务规则（V1.7新增）：推演完成后，系统自动从报告的"分阶段行动计划"中提取短期（0-6个月）行动项（3-5条），生成待办看板存储于浏览器本地。用户勾选完成时记录完成时间。该完成记录在用户进入复盘模块时自动预填"现实发生情况"字段（用户可编辑修改），实现执行数据到复盘的自动流转。3.3
